# Homebrew tap for Udaya Lakmal's apps

## Grammable

Free, open-source AI grammar checker & rewriter for macOS.
Uses Claude Code, Codex CLI, Gemini CLI, Ollama, LM Studio or Apple Intelligence. No subscription.

```bash
brew install --cask udayalakmal/tap/grammable
```

Upgrade:

```bash
brew upgrade --cask grammable
```

Uninstall (add `--zap` to also remove presets, logs and settings):

```bash
brew uninstall --cask grammable
```

Project: https://github.com/UdayaLakmal/Grammable

## MacClipHistory

Free, open-source clipboard history manager for Mac, like Windows Win+V.
Press ⌃⌘V anywhere to search everything you copied and paste it.

```bash
brew install --cask udayalakmal/tap/maccliphistory
```

Upgrade:

```bash
brew upgrade --cask maccliphistory
```

Uninstall (add `--zap` to also remove your clipboard history):

```bash
brew uninstall --cask maccliphistory
```

Project: https://github.com/UdayaLakmal/MacClipHistory

> Homebrew 7 asks you to trust third-party taps once. If you see
> "Refusing to load cask … from untrusted tap", run `brew trust udayalakmal/tap`.
